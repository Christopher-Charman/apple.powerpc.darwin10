# XNU-1504.15.3 PPC kernel export pipeline error propagation

The PowerPC kernel linker-export generator previously used a grep/awk/sort pipeline. The shell only checked the final sort exit status, so an export-file read failure after the file-existence preflight could silently yield an incomplete PPC symbol list. This change uses a checked AWK normalization stage followed by checked sorting and the existing atomic destination rename. The normalized output remains equivalent to the original grep passes: lines without a colon remain intact, while lines containing a colon contribute their second field; duplicates are sorted away.

The pristine Apple 10.6.8 snapshot is unchanged. Patch: patches/xnu-1504.15.3-ppc-linker-export-pipeline-errors.patch. Source-only regression: tests/test_xnu_ppc_linker_pipeline.py. No compilation or linking.
