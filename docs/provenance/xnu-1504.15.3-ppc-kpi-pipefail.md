# XNU PowerPC KPI source-read failure propagation

The prior atomic report generator still used sed|sort, which returned the final sort status even if sed could not read an architecture-specific source. The Bash script now enables pipefail within the normalization subshell. A failed source read cannot replace the previously valid SupportedKPIs-ppc.txt; symbol normalization and output ordering are unchanged.

The Apple 10.6.8 release snapshot remains immutable. Patch: patches/xnu-1504.15.3-ppc-kpi-pipefail.patch. Regression: tests/test_xnu_ppc_kpi_pipefail.py. Source-script checks only; no compilation or linking.
