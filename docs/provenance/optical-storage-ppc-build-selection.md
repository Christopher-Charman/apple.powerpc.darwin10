# Optical storage families: PPC build selection

Official 10.6.8 Apple OSS snapshots: IOBDStorageFamily-10, IOCDStorageFamily-47.1, IODVDStorageFamily-30. The original IOCD architecture patch selected `ARCHS = ppc` only in the Headers aggregate target's Debug and Release configurations; its metadata's project-wide description was inaccurate. The native IOCD KEXT target has separate configurations, now pinned to `ppc` by [`IOCDStorageFamily-47.1-ppc-kext-arch.patch`](../../patches/IOCDStorageFamily-47.1-ppc-kext-arch.patch). See the [source provenance](iocdstoragefamily-47.1-ppc-kext-arch.md). The pristine Apple release source remains unchanged. This is source-only architecture selection; no build, linkage, kernel ABI, device or media validation has been performed.
