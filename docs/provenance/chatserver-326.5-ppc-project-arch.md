# ChatServer-326.5 PowerPC Xcode architecture

`ChatServer-326.5` is the official Apple Mac OS X 10.6.8 release member in `source-releases/10.6.8.json`. Apple's [ChatServer-326.5 tag](https://github.com/apple-oss-distributions/ChatServer/tree/ChatServer-326.5) is commit `3a65c907526b8ae4f610fc60b93b2855fe7ddc87`; its Xcode project blob is `2622ff11bdbc329cb5fb0ca3ebf26686539761d8`. The working project before this change had that same blob as the pristine `src/releases/10.6.8/ChatServer-326.5/` snapshot. The snapshot remains unchanged. Apple copyright and third-party license notices remain in their existing source files.

The PowerPC-compatible [ChatServer-263.1 Leopard tag](https://github.com/apple-oss-distributions/ChatServer/tree/ChatServer-263.1), commit `d7766260fa6fc2c32ce51e2bc6989f0224956704`, includes `ppc` in its Xcode Release architecture list. The later [326.1 tag](https://github.com/apple-oss-distributions/ChatServer/tree/ChatServer-326.1) uses the same Intel-only Xcode project blob as 326.5. In 326.5 the legacy `ChatServer2` target's Release setting, the project Debug setting, and both `libxmppodauth` target settings explicitly omit `ppc`. The `ChatServer2` Makefile still enumerates `ppc` in `BUILD_ARCHS`, selects a PPC build host, and retains PPC configuration cache and GLib patches. Thus the Xcode exclusions conflict with the remaining PPC source path.

The patch adds `ppc` to those four active `ARCHS` lists, ahead of the retained Intel entries. It changes no source implementation, vendor archive, Makefile, deployment setting or pristine snapshot. The legacy server target and `libxmppodauth` are the immediate consumers; runtime interfaces to Open Directory, SASL, Jabber and bundled libraries remain unverified. This is a PPC32 source selection correction; it makes no PPC64, compilation, linking or runtime claim.

Exact patch: `patches/ChatServer-326.5-ppc-project-arch.patch`. Source-only regression: `tests/test_chatserver_ppc_project_arch.py`. Verification reads source text and checks the complete delta against the official 10.6.8 snapshot. No build tool or compiler was run.
