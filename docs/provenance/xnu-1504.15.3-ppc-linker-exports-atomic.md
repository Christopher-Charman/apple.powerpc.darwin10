# XNU-1504.15.3 PowerPC linker export atomic output

The prior working-tree fix validated missing PPC linker-export inputs, but the shell redirection still opened the destination before generation finished. This incremental change writes into a same-directory temporary file and renames it into place only after successful completion. The official Apple 10.6.8 source remains pristine. The existing symbol normalization and sorting logic is preserved.

Patch: patches/xnu-1504.15.3-ppc-linker-exports-atomic.patch.
Regression: tests/test_xnu_ppc_linker_atomic.py executes the shell generator on PPC-style source fixture files, verifies replacement of a stale output, and verifies an invalid input preserves the prior output. These are source-script tests, not compilation or linking.
