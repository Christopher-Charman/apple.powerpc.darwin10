# IOKitTools-78: guard ioreg registry entry ID output on PowerPC

**Target and source.** The editable `src/powerpc/IOKitTools-78/ioreg.tproj/ioreg.c` was byte-identical to the pristine `src/releases/10.6.8/IOKitTools-78/` snapshot and Apple's [IOKitTools-78 tag](https://github.com/apple-oss-distributions/IOKitTools/tree/IOKitTools-78), commit `5376e07d761f9dae2857f6827a40305f9eccc9b6`. The pristine component tree is `c684c84aaf15faf330e18f3965376613e66bd9d7`; the original `ioreg.c` blob is `a7f48e31ff3e150143eb89fca0fe2ed0e777d3bf`. The 10.6.8 release manifest names IOKitTools-78. Apple license headers are retained.

**Predecessor and successor.** Apple's [IOKitTools-76 tag](https://github.com/apple-oss-distributions/IOKitTools/tree/IOKitTools-76), commit `d8fbadc721054b4d9aee1accd1f6b0166d850267`, is the official 10.5.8 PPC-compatible predecessor. It has no registry entry ID print in `ioreg -s`. Apple's [IOKitTools-82 tag](https://github.com/apple-oss-distributions/IOKitTools/tree/IOKitTools-82), commit `f048daefa618ffbc6b85b6570ec4ef9f909419cb`, retains the 78 behavior but removes the stray semicolon after `if (status == KERN_SUCCESS)`. Only that isolated correction is adopted; the 10.6.8 source and dependencies stay pinned.

**Defect and correction.** `IORegistryEntryGetRegistryEntryID` returns a `kern_return_t` status and writes the ID through an output pointer. In IOKitTools-78, `if (status == KERN_SUCCESS);` has an empty body, so the following `print` runs even on failure. The target `IOKitUser-514.16.50/IOKitLib.c` zeroes the output on failure, producing a false `id 0x0` in `ioreg -s` on that path. Removing the semicolon makes output conditional on success, exactly as Apple did in version 82. This is applicable to the retained `ppc` architecture in the IOKitTools-78 project without changing ABI or target selection.

**Patch and verification.** `patches/IOKitTools-78-ioreg-entry-id-ppc.patch` is the exact one-character working-source diff; its adjacent JSON pins the pristine tree. `tests/test_iokittools_ppc_entry_id.py` verifies the pristine blob, the sole source delta, and the lookup-to-print guard. The dedicated `iokittools-ppc-entry-id-source.yml` workflow runs this Python test without changing the shared source-graph workflow under an older open PR. All verification is source-only. No compilation, linking, CI compilation, or PowerPC hardware/runtime behavior is claimed.
