# IOGraphics-392.1: PowerPC clamshell PMU result

**Target and source:** Darwin 10.6.8 PowerPC working source at `src/powerpc/IOGraphics-392.1/IOGraphicsFamily/IOFramebuffer.cpp`. Apple's official [IOGraphics-392.1 tag](https://github.com/apple-oss-distributions/IOGraphics/tree/IOGraphics-392.1) resolves to commit `2e341c2cee640a8a684c3593035193b17ddbbbb1`, tree `ed07eb1e310d0f0a2ac01946619e0590e37ce60d`. The pristine `src/releases/10.6.8/IOGraphics-392.1/` has that exact tree. Before this change, the working component matched the release tree except for the previously documented three `ARCHS = ppc` project settings. The affected upstream source blob is `61909b23a44d09f5e84a84360e1a3eff5284c94c`.

**PPC predecessor:** Apple's [IOGraphics-305.14 tag](https://github.com/apple-oss-distributions/IOGraphics/tree/IOGraphics-305.14), listed for Mac OS X 10.5.8, resolves to commit `ceee58735167f843cbd7fcf577c337ef1ade9067`, tree `d3b35eaa1731a5b3b19894b5e26f55200b7e95f7`. Its corresponding `IOGetHardwareClamshellState` PPC branch declares `IOReturn ret = kIOReturnUnsupported` before assigning the result of `ApplePMUSendMiscCommand`.

**Defect and correction:** In 10.6.8 Apple refactored the PMU read into `IOFramebuffer::readClamshellState()`. Its `#if __ppc__` branch assigns the PMU call result to `ret` and tests it, but has no declaration for `ret`. The separate Intel branch declares a local `IOReturn ret` inside its ACPI block. This is a PPC source-level name-resolution error in the graphics family. Declare and initialize `IOReturn ret` at the PPC PMU call. The exact one-line working-source diff is `patches/IOGraphics-392.1-ppc-clamshell-ret.patch`, pinned by the adjacent JSON. The upstream release snapshot and existing architecture patch remain untouched.

**Verification:** The source-only `IOGraphicsClamshellTests` in `tests/test_ppc_source_guards.py`, run by the existing `source-graph` workflow, pins the pristine Apple blob, checks the exact one-line working-source delta and patch, and verifies that the PPC branch tests the declared PMU result before updating clamshell state. No compile, link, build, hardware, or runtime result is claimed.
