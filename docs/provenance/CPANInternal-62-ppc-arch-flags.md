# CPANInternal-62: derive RC_CFLAGS from selected architectures

**Target:** The tracked PowerPC working file `src/powerpc/CPANInternal-62/Makefile` for Darwin 10.6.8 PPC32/PPC64. The official Apple `CPANInternal-62` tag is commit `1e87594754f0bf2f18251115671409c6d78950dc`. Before this change, the working and pristine `src/releases/10.6.8/CPANInternal-62` trees were both `c0dcb2bd195e4d27a79575244c4a8485b7f9a7eb`; the pristine Makefile blob is `b38eb673184e4c9fa648818fa7593ee2d3b708d0`. The release snapshot is unchanged.

**Comparison:** Apple's earlier [CPANInternal-32](https://github.com/apple-oss-distributions/CPANInternal/tree/CPANInternal-32), commit `474d4ec4624bf950b6e2e49a8f2ca39763f126ca`, selected modules by Leopard-or-newer but did not establish `RC_CFLAGS`. The exact 10.6.8 `perl-63` dependency, commit `3e8516707574e39d4dda8e171bfa6db3f1c6f7f4`, provides a more relevant same-release precedent: its Makefile derives and exports `RC_CFLAGS` from `RC_ARCHS` when the caller did not supply flags.

**Defect:** The CPAN Makefile lists Snow Leopard's default `ARCHFLAGS` as Intel-only, but that variable is only reported and does not reach module configuration. The actual architecture input is `$ENV{RC_CFLAGS}`: `add_rc_constants.pl` injects it into ExtUtils::MakeMaker compile and link flags; `PathTools/Build.PL` and the applied `version.diff` consume it for Module::Build compile and link flags. If ReleaseControl supplies `RC_ARCHS=ppc` or `ppc ppc64` without `RC_CFLAGS`, these scripts receive no selected architecture flags. The sibling Perl project already handles this case.

**Correction:** In the working CPAN Makefile, use Perl's same conditional fallback: derive `RC_ARCHS` from `arch` only when absent, then export `RC_CFLAGS` as `-arch` per selected architecture plus any `RC_NONARCH_CFLAGS` only when absent. An explicit caller `RC_CFLAGS` remains authoritative. The exact one-hunk working-source delta is [`patches/CPANInternal-62-ppc-arch-flags.patch`](../../patches/CPANInternal-62-ppc-arch-flags.patch).

**Verification:** `python3 -m unittest discover -s tests -p test_ppc_source_guards.py -k CPANInternal -v` checks the pristine blob, exact patch, conditional export, same-release Perl precedent and three existing XS flag consumers. These are source-only checks. No compilation, linking, build tool, CI compilation or hardware test was run. This correction establishes the intended flag path for the identified consumers; full module coverage and PPC runtime remain unverified.
