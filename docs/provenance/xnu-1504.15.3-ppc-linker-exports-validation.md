# XNU-1504.15.3 kernel linker exports input validation

The pristine 10.6.8 script is src/releases/10.6.8/xnu-1504.15.3/config/generate_linker_exports.sh. The PowerPC working script matched it before this patch.

The XNU config/Makefile build_mach_kernel_exports rule invokes this generator on architecture-specific export lists, including the PPC sets. The upstream shell pipeline can silently succeed when an input is missing because the final sort exits successfully. Validate every required input before truncating the output, while retaining both upstream grep passes, colon field normalization, and sort -u output. Empty match sets remain valid. This prevents a missing PPC KPI export file from silently generating an incomplete kernel link symbol list; it does not change exported symbol policy.

Patch: patches/xnu-1504.15.3-ppc-linker-exports-validation.patch. Tests execute the actual script with PPC-style export fixture data and missing files. No kernel link or hardware boot performed.
