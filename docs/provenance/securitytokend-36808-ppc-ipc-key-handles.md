# SecurityTokend-36808: PPC IPC key handle translation

**Target and provenance:** The editable source is `src/powerpc/SecurityTokend-36808/lib/transition.cpp`. Apple's official [SecurityTokend-36808 tag](https://github.com/apple-oss-distributions/SecurityTokend/tree/SecurityTokend-36808) is commit `4883b6673ee521f082a7d9c6c3a34f73e596af69`, tree `84bf32ccb71c46e98aea7040e4703edaf463a415`. The tree matches the pristine `src/releases/10.6.8/SecurityTokend-36808/` and the working component before this change; `lib/transition.cpp` is blob `77784cf8d9421a751ca95d8bb1d2d4690067d40c`. Apple's license text remains intact.

**Predecessor comparison:** Official [SecurityTokend-32363](https://github.com/apple-oss-distributions/SecurityTokend/tree/SecurityTokend-32363), commit `600d7a6d6b6464cd8dda9df592e8fcfb03523e48`, tree `fe53ba5468b9d6da151e7218b47903acb987271b`, is the earlier PowerPC-era source. Apple's [32363-to-36808 comparison](https://github.com/apple-oss-distributions/SecurityTokend/compare/SecurityTokend-32363...SecurityTokend-36808) introduced the `TokendHandleObject` translation in the server transition layer. The older version passed handles directly because it had no translation map. The 36808 code maps received IPC handles for `unwrapKey`, key operations, ACL operations and the subject key of `wrapKey`, but still passes `hWrappingKey` in `wrapKey` and `hBaseKey` in `deriveKey` directly to native tokend calls.

**Defect and correction:** `transit.h` declares a `uint32_t` IPC handle mapped to a native-sized `CSSM_HANDLE`; `transit.cpp` converts via `findTDHandle`, returning zero for zero or unknown IPC handles. The two missed call sites can therefore send an IPC map key in place of the native key handle, especially relevant to PPC64 and also incorrect on PPC32 when map and native values differ. Translate both inputs using the existing helper, preserving the helper's zero/invalid semantics and all later 10.6.8 APIs. The companion patch is the exact working-tree delta. No snapshot is modified.

**Dependency and limits:** This server transition is consumed by the Security tokend client and the native tokend implementation through the existing MIG and CSSM interfaces. The change is confined to the two key-handle arguments; no ABI or MIG definition changes. `python3 -m unittest discover -s tests -p 'test_securitytokend_ppc_ipc_key_handles.py' -v` checks the pinned Apple blob, exact source delta, and server translation structure. `python3 tools/ppc_patch_gate.py patches/SecurityTokend-36808-ppc-ipc-key-handles.json` checks the release pin and patch. These are source-only checks. PPC compilation, linkage, and hardware behavior remain unverified.
