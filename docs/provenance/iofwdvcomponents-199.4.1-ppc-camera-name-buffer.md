**Defect and correction:** `cameraNameLookup` receives `UInt8 *name`, and its only call passes a `Str255 cameraName` array. Two `CFStringGetPascalString` calls pass `sizeof(name)` as the output capacity. On PPC32 that is the four-byte pointer size, rather than the 256-byte `Str255` storage. Thus the localized vendor-plus-`DV` name cannot fit, so the code falls back to `DV`. Use `sizeof(Str255)` for both the localized conversion and fallback. The exact working-source diff is `patches/IOFWDVComponents-199.4.1-ppc-camera-name-buffer.patch`; its pinned metadata is the adjacent JSON. No release snapshot, architecture setting, framework interface or other component changes.

The patch metadata pins the pristine tree; the patch itself is the exact diff to the editable working source. This is a source-only check.
