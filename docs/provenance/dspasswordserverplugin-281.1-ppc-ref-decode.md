# DSPasswordServerPlugin 281.1: PowerPC password reference decode bound

Target: the first-party Mac OS X 10.6.8 `DSPasswordServerPlugin-281.1` source, in the tracked `src/powerpc/` working tree. Apple's [official tag](https://github.com/apple-oss-distributions/DSPasswordServerPlugin/tree/DSPasswordServerPlugin-281.1) resolves to commit `df46f103d4712e066acb37a762258b811326640f`. Its `AuthFile.mm` Git blob is `ebcea052ae353a8778b4acd73a80c58c0c3368eb`; the pristine `src/releases/10.6.8/DSPasswordServerPlugin-281.1/AuthFile.mm` and pre-patch working file have that same blob. Apple's APSL 2.0 notice remains in the source.

The historical PowerPC-era [208.6 tag](https://github.com/apple-oss-distributions/DSPasswordServerPlugin/tree/DSPasswordServerPlugin-208.6), commit `bde9f2bcd8ef3cf795981b29d2c6854242507109`, has the same bound in `AuthFile.mm` blob `57263ef29b0dadbfed2439d80bbeabd860aa49d4`. This is an inherited defect, so the older source is comparison evidence rather than a replacement donor.

`pwsf_stringToPasswordRecRef` passes 32 hex characters to `ConvertHexToBinaryFastWithNtoHL`. Four leading `UInt32` fields in `PWFileEntry` form the 16-byte reference. The `TARGET_RT_BIG_ENDIAN` loop consumes two hex characters and writes one byte per iteration but used `idx < len`, making a 32-character reference trigger 32 writes and 64 character reads. On big-endian PowerPC this overwrites 16 bytes beyond the reference and reads past the string. The little-endian branch already converts 32 characters to 16 bytes.

The exact [patch](../../patches/DSPasswordServerPlugin-281.1-ppc-ref-decode.patch) changes the big-endian loop bound to `len / 2`. No other source path or pristine snapshot changes. The source-only regression pins the Apple blob, verifies the one-line working-tree delta and checks the 32-character/16-byte contract with a sentinel fixture. It does not establish successful PPC compilation, linkage, authentication behavior or hardware runtime results. The DirectoryService consumer and password database integration remain unverified.
