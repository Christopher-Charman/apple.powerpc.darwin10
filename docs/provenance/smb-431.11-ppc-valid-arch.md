# smb-431.11 PowerPC target validity

`smb-431.11` is the official Apple 10.6.8 source member pinned in `source-releases/10.6.8.json` and distributed under APSL 2.0. The pristine `src/releases/10.6.8/smb-431.11/smb.xcodeproj/project.pbxproj` blob is `436f4c13948cd6c42f8fb191d6c870ad82219c2e` and remains unchanged. The working project file matched it before this patch.

The `mount_smbfs`, `smbutil`, `smbfs` kernel extension and `load_smbfs` helper targets all select the existing `ppc i386 ppc64 x86_64` architecture macro. Their Development, Deployment and two Rosetta configurations restrict `VALID_ARCHS` to `i386 x86_64`, discarding PowerPC. The source patch adds `ppc` to those 16 lists. It does not enable `ppc64`, whose kernel and ABI compatibility is unverified, or alter other targets. The checked-in launchd service names the `load_smbfs` helper inside `smbfs.kext`; the helper and kernel extension must be selected together for this source dependency.

Patch: `patches/smb-431.11-ppc-valid-arch.patch`. Regression: `tests/test_smb_ppc_valid_arch.py`. This is source-only validation; compilation, linking, build, protocol interoperability and hardware behavior remain unverified and are prohibited in this session.
