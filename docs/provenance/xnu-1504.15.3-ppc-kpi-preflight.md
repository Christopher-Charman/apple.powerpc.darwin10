# XNU-1504.15.3 PPC KPI preflight correction

The preceding PowerPC list_supported.sh change introduced missing-export validation, but wrote its output before checking all four required source files. If a later source file was missing, the generated SupportedKPIs-ppc.txt could be left incomplete and overwrite an earlier valid artifact.

Preflight all four PPC (or ALL) source export files before opening the output. Preserve existing formatting and symbol normalization. This is an incremental patch relative to the current PowerPC working file; the official src/releases/10.6.8 source remains unchanged.
