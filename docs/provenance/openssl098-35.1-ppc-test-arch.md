# OpenSSL098-35.1 PowerPC test architecture selection

The 10.6.8 release manifest names Apple OSS [`OpenSSL098-35.1`](https://github.com/apple-oss-distributions/OpenSSL098/tree/OpenSSL098-35.1), commit `e1f142d5ef1aeabcfa0bf4e08518bdcd332c7e2e`, tree `a7a892ee95c12b5d59c947b759fb283982206c97`. The editable `src/powerpc/OpenSSL098-35.1` tree initially matched that tag and the pristine `src/releases/10.6.8/OpenSSL098-35.1` tree. The affected `bin/test_functions.sh` blob was `dee2b677d3848a0f39591921293057567754e3c3`; Apple's immediate official predecessor [`OpenSSL098-35`](https://github.com/apple-oss-distributions/OpenSSL098/tree/OpenSSL098-35) has the same blob. The script retains its original Apple/OpenSSL attribution in the unchanged release snapshot.

Apple's `src/Configure` provides `darwin-ppc-llvm`, `src/MacOS/buildinf.h` identifies `darwin-ppc-llvm`, and the Xcode project includes PPC preprocessor settings and `ppc` in `VALID_ARCHS`. Yet `bin/test_functions.sh` unconditionally excludes `ppc` from `get_exec_arches`, even if a PPC-capable shell is present. The test targets call this helper before launching built test programs. On a PPC-only restored system, the hardcoded exclusion selects no architecture and prevents the tests from exercising the PPC programs. Apple's original comment says there was no PPC `/bin/sh` on its Snow Leopard environment; that is a host capability condition, not a property of PPC code.

The working source now probes the actual `/bin/sh` used by the test scripts under `arch -${arch}`. A host with a PPC-capable shell includes `ppc`; a host without one still excludes it. The same probe applies to existing non-PPC architectures. No crypto algorithm, ABI, generated configuration, or immutable release source changes. The exact working-tree delta is `patches/OpenSSL098-35.1-ppc-test-arch.patch`, with its release pin in the companion JSON manifest.

`tests/test_openssl098_ppc_test_arch.py` checks the pristine blob and exact patch, then sources the helper under a stub `arch` command to verify PPC inclusion, conditional PPC exclusion, and i386 control behavior. These are source-script tests only. No compilation, linkage, OpenSSL binary execution, or PowerPC hardware result is claimed.
