# XNU-1504.15.3 PowerPC KPI export list generation

Upstream: src/releases/10.6.8/xnu-1504.15.3/config/list_supported.sh, immutable and byte-identical to the working script before this patch.

The XNU build generates architecture-specific SupportedKPIs-ppc.txt using the PPC export lists. The original script expanded the output filename without quoting and used unquoted ARCH in shell tests. This patch quotes all file paths and architecture tests, checks the three required arguments, fails on missing export files, and retains the four existing KPI categories, sorting and symbol normalization. It does not modify the PPC exported ABI list or invent symbols. The output is generated by the existing XNU build rule.

Incremental patch: patches/xnu-1504.15.3-ppc-kpi-list-quoting.patch. The accompanying tests execute the actual shell script with PPC and ALL fixture exports and paths containing spaces. Full XNU kernel compile and PPC boot remain unverified.
