# CF-550.43: restore the PowerPC64 HALT guard

**Target:** Darwin 10.6.8 `src/powerpc/CF-550.43/CFInternal.h`. The first-party `source-releases/10.6.8.json` lists `CF-550.43`. Its pre-change working tree and pristine `src/releases/10.6.8/CF-550.43/` share Git tree `979bfb3871fa956cb8b537eda1bea777a663a90c`; the original header blob is `7f8d9a6e01ab538f1d7f74b2c0d26b0ba04a9706`. The release snapshot and APSL 2.0 notice remain intact.

**Upstream and predecessor:** Apple's [CF-550.43 tag](https://github.com/apple-oss-distributions/CF/tree/CF-550.43) points to `49c349e5852474570d014ba9c7ba2df52f66d6ce`; [CF-550.42](https://github.com/apple-oss-distributions/CF/tree/CF-550.42) at `6ed0bb533dec23660e53f4fe5c422ffe8c1ff338` has the same missing PPC64 guard. The last Leopard [CF-476.19](https://github.com/apple-oss-distributions/CF/tree/CF-476.19) at `e92003b7fb6f7be08ee3723e6004ec155c88527a` explicitly defines `HALT` under `defined(__ppc__) || defined(__ppc64__)`. Apple's [64-Bit Transition Guide for Cocoa](https://leopard-adc.pepas.com/documentation/Cocoa/Conceptual/Cocoa64BitGuide/Cocoa64BitGuide.pdf), table 3-1, identifies `__ppc__` as 32-bit PowerPC and `__ppc64__` as 64-bit PowerPC.

**Defect:** Snow Leopard's `CFInternal.h` defines `HALT` for `__ppc__`, x86, and ARM, but omits `__ppc64__`. `CFRuntime.c` uses `HALT` in active paths including `CFRetain` and `CFRelease`. A PPC64 source selection therefore leaves those tokens undefined. This is a source-level finding; no compiler was run.

**Correction:** Add `defined(__ppc64__)` to the existing PowerPC guard, retaining Snow Leopard's trap and process-kill behavior for both PowerPC modes. The exact one-line diff is `patches/CF-550.43-ppc64-halt.patch`, pinned to the release tree by `patches/CF-550.43-ppc64-halt.json`. No other architecture branch changes.

**Verification and limits:** `python3 -m unittest discover -s tests -p 'test_cf_ppc64_halt.py' -v` checks the pristine Apple blob, exact patch, both PowerPC guards, and an active `HALT` consumer. The required source-graph workflow runs this source-only test. No compilation, linking, build tool or hardware run occurred. PPC64 CoreFoundation build selection, ABI, and runtime behavior still require separate validation under an explicitly authorized process.
