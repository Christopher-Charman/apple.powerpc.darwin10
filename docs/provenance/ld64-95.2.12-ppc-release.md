# ld64-95.2.12 PowerPC Release target

The 10.6.8 ld64 Xcode project contains a Release configuration for `ld` with `ARCHS = x86_64` despite `VALID_ARCHS = "x86_64 i386 ppc"` and `GCC_MODEL_TUNING = G5`. This changes the Release target to `ARCHS = ppc` in the tracked `src/powerpc/` source. The original `src/releases/10.6.8/` is unchanged. The patch is a reviewable diff against the initial working source tree. Linker code-path and PPC output compatibility require separate source-level examination and validation; no compilation on PowerPC-Darwin.org.
