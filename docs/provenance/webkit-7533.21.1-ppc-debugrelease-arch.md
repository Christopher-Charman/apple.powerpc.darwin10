# WebKit 7533.21.1: select PowerPC in 10.6 development configurations

Target: Apple's exact [WebKit-7533.21.1](https://github.com/apple-oss-distributions/WebKit/tree/WebKit-7533.21.1) 10.6.8 release member, annotated tag resolved to commit `b1689f2c1aecee0ef35f1ae492672aec4085462b`, tree `624549ce961623b62130e9bdea06b00f4eca3851`. Before this change, `src/powerpc/WebKit-7533.21.1/` and the immutable `src/releases/10.6.8/WebKit-7533.21.1/` both had that exact Git tree identity. The Apple source license and notices are retained.

Predecessor: Apple's [WebKit-6531.9](https://github.com/apple-oss-distributions/WebKit/tree/WebKit-6531.9) 10.6.0 source, annotated tag resolved to commit `e5113622f64f714c69c35479a593295cef061522`, tree `8c2125f519fdd7f5e712d1c900bceb6c03f4d7fb`. Its Mac configuration uses `$(NATIVE_ARCH)` for the PPC-compatible 10.5 target, lists `ppc` and `ppc64` in `VALID_ARCHS`, and has PPC-specific exported-symbol paths. The 10.6.8 source retains those PPC facilities, but its Mac Debug/Release `ARCHS_1060` line selects only `$(ARCHS_STANDARD_32_64_BIT)` and does not explicitly select either PowerPC architecture. The WebKit target's Debug/Release project configurations consume that file. The repository's accepted JavaScriptGlue 7533.19.1 source change uses the same architecture-selection correction for its PPC32 target.

Correction: add `ppc ppc64` to `ARCHS_1060` in the tracked WebKit working source. Keep the standard 32/64-bit architecture expansion (and therefore the existing Intel selection), 10.5/10.7 settings, and deployment targets. WebKit's `Base.xcconfig` already admits both PPC architectures and `WebKit.xcconfig` already names their exported-symbol files. The exact one-line delta is `patches/WebKit-7533.21.1-ppc-debugrelease-arch.patch`, with manifest `patches/WebKit-7533.21.1-ppc-debugrelease-arch.json`. The pristine release snapshot is unchanged.

`tests/test_webkit_ppc_debugrelease_arch.py` checks the exact release-to-working source replacement and patch bytes, confirms the project consumes the configuration, and checks the preserved architecture, symbol-export, and deployment settings. `source-graph` runs this test and the read-only patch gate. These are source-only checks. JavaScriptCore and WebCore have separate architecture selection and dependency contracts; this WebKit change alone does not establish their PPC compatibility. No compilation, linking, build, or hardware test was performed.
