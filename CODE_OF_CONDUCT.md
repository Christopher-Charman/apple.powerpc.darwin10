# Community conduct

This project welcomes technical contributions from developers, archivists and hardware testers.

Discuss claims and patches on their technical merits. Be respectful, credit original work, avoid personal attacks or harassment, and do not publish private information. Maintainers may moderate disruptive contributions and interactions. For ordinary technical disputes, use issues and PR review with reproducible evidence. For sensitive conduct concerns, contact the repository owner privately through an appropriate GitHub contact channel rather than posting personal information publicly.
